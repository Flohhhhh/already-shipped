# Architecture

already-shipped is a single Next.js app. It answers whether a feature idea already exists in [T3 Code](https://github.com/pingdotgg/t3code), and it keeps a public list of ideas that do not.

## Stack

- Next.js App Router, React, TypeScript, Tailwind, shadcn/ui (Base UI, Nova preset). The UI uses Instrument Sans, grayscale surfaces, and a bottom sheet for navigation on small screens.
- Vitest for unit tests. Prettier, ESLint, and `tsc` for static checks.
- Convex for the proposed-feature list and votes. There is no authentication and no CMS.
- Package manager: pnpm. One app, no workspace packages.

## Routes

```text
src/app/layout.tsx                 # theme and optional Convex providers
src/app/(public)/layout.tsx        # name, theme switch, unofficial footer
src/app/(public)/page.tsx          # /
src/app/(public)/proposed/page.tsx # /proposed
```

`/` is a search form. The query string `q` is the feature idea, and `pick` selects one of that search’s matches. `/proposed` is the public list. `/api/suggest` returns a few title matches for the search field.

## Search

Search reads `data/feature-index.json`, generated by `pnpm index` from public T3 Code sources. The default matcher is lexical: normalized tokens, a small synonym map, light fuzzy matching, and heavier weight on setting titles. It does not call a paid API.

Set `ALREADY_SHIPPED_MATCHER=embeddings` plus an OpenAI-compatible embeddings endpoint to rerank. If the endpoint, key, model, or `data/feature-embeddings.json` is missing or the request fails, search uses the lexical matcher.

## Proposals

Ideas that do not match can be proposed. Convex stores the text, a canonical token key, and one vote per browser-generated voter id. Near-duplicate text supports the existing row instead of creating another. The app runs search without Convex; the proposal list explains that a deployment is required.

## Environment

Next.js env is validated in `src/env.ts` with `@t3-oss/env-nextjs`. Convex deployment variables stay in `.env.local` and are not imported into Convex functions. `SKIP_ENV_VALIDATION=1` skips Next.js env validation for tooling only.

## Themes and Git

Light, dark, and system themes use `next-themes`. Small screens open Search and Requests from a swipeable bottom sheet; wider screens keep that navigation in the header. Branches: `main`, `development`, and feature branches. GitHub Actions runs Prettier, lint, typecheck, and unit tests separately.
